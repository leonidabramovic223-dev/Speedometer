«Датчики»: курс и наклон по кватерниону (Madgwick), скорость по акселерометру. GPS используется только для начальной точки. «Стоп-ноль» — когда машина стоит.

GPS в этом режиме не корректирует скорость и курс — только задаёт начальную координату для карты. Курс ведётся гироскопом и кватернионом, поэтому стрелка не улетает при наклоне телефона. Карта со временем расходится с реальностью — это нормально для счисления пути.
